Section 07
Key SQL Queries
Core analytical queries used to derive insights from the database
-- Content Growth Analysis: Titles added per year
SELECT year_added,
    COUNT(*) AS total_titles,
    SUM(CASE WHEN type = 'Movie' THEN 1 ELSE 0 END) AS movies,
    SUM(CASE WHEN type = 'TV Show' THEN 1 ELSE 0 END) AS tv_shows
FROM netflix_titles
WHERE year_added IS NOT NULL
GROUP BY year_added
ORDER BY year_added;
-- Top Genres: Content distribution by primary genre
SELECT genre_primary,
    COUNT(*) AS title_count,
    ROUND(COUNT(*) * 100.0 / (SELECT COUNT(*) FROM netflix_titles), 2) AS percentage
FROM netflix_titles
WHERE genre_primary IS NOT NULL
GROUP BY genre_primary
ORDER BY title_count DESC
LIMIT 10;
-- Country Analysis: Top content-producing nations
SELECT country_primary,
    COUNT(*) AS total,
    SUM(CASE WHEN type='Movie' THEN 1 ELSE 0 END) AS movies,
    SUM(CASE WHEN type='TV Show' THEN 1 ELSE 0 END) AS tv_shows
FROM netflix_titles
WHERE country_primary IS NOT NULL
GROUP BY country_primary
ORDER BY total DESC
LIMIT 15;

📐 Data Pipeline Architecture
Step 1 — Ingestion: Raw Netflix dataset (8,807 rows × 12 columns) downloaded from public GitHub repository.

Step 2 — Cleaning: Python (pandas) script handled null values, fixed misplaced duration/rating fields, standardized date formats, extracted primary country/genre/director from multi-value fields.

Step 3 — Storage: Cleaned data loaded into SQLite database with proper schema, indexes, and normalized tables via SQL setup scripts.

Step 4 — Analysis: 5 layered SQL scripts executed — database setup → data cleaning → exploratory analysis → business insights → advanced analytics.

Step 5 — Visualization: Key aggregations exported to JSON and rendered in an interactive JavaScript dashboard using Chart.js with a cinematic dark UI.

Section 09
Business Insights Summary
Actionable takeaways from the analysis
📈 Growth Peak
Netflix's content additions peaked in 2019–2020, with significant acceleration from 2016 onward. This correlates with Netflix's global expansion into 190+ countries in 2016 and aggressive original content spending.
🎬 Movie-Heavy Strategy
Movies constitute ~69.6% of the catalog, but TV shows drive higher engagement per subscriber due to episodic consumption. Netflix has been increasing its TV show ratio year-over-year.
🌏 Global Localization
Content from 86+ countries signals deep localization. Indian, Korean, and European content has grown rapidly, with shows like Squid Game demonstrating massive global crossover potential.
⏱️ Optimal Movie Length
Average movie duration of 99.6 minutes aligns with cinema standards. Netflix's algorithm favors completion rates, making shorter films statistically more likely to receive promotion on the platform.
